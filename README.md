# Inventory Management System

A Java console application for registering and managing product inventory through an interactive menu.

## Features

- Registers products with name, price, and quantity.
- Displays all registered products and their information.
- Searches for products by name.
- Calculates the total value of the inventory.
- Prevents additional entries when the inventory reaches its maximum capacity.
- Provides a menu-based interface for accessing each function.

## Technologies

- Java
- Arrays
- Scanner
- Switch statements
- Loops
- Conditional logic

## Menu Options

The application provides five options:

1. Add product
2. Show products
3. Search products
4. Calculate inventory value
5. Exit

Each registered product stores its name, price, and quantity.

## How to Run

1. Make sure the Java Development Kit (JDK) is installed.
2. Download or clone this repository.
3. Open a terminal in the directory containing `InventoryManager.java`.
4. Compile the program:

```bash
javac InventoryManager.java
```

5. Run the program:

```bash
java InventoryManager
```

The application will display the inventory management menu in the terminal.
